# 魔方雪茄柜 · LED 触控面板演示

单文件交互演示页（`index.html`），用于向客户演示底座 436mm LED 电容触摸面板的操作逻辑。

- 图标线条、尺寸关系取自设计稿 `魔方UI-01.svg`（模式切换、灯光、WIFI、灯光状态、报障、上下箭头）
- 零依赖、零外部请求：不联网也能双击打开
- 支持横屏（16:9）与竖屏两套排布

## 演示内容

| 操作 | 效果 |
| --- | --- |
| 点「模式切换」图标 | 自定义模式 → 醇养模式 → 醒茄模式 循环，数值随模式切换 |
| 点「灯光」图标 | 低 → 中 → 高 三档亮度循环，灯泡、状态灯、环境光晕同步变化 |
| 自定义模式下点温度上下箭头 | 16–22℃ 步进 ±1 |
| 自定义模式下点湿度上下箭头 | 60–80% 步进 ±1 |
| 醇养 / 醒茄模式 | 上下箭头隐藏（温湿度为预设值），切模式时短暂提示 |
| 状态灯 | WIFI 常亮、灯光随亮度、报障常暗（正常状态） |

自定义模式下调整过的温湿度会被记住：切到其他模式再切回来，数值保持不变。

## 本地预览

直接双击 `index.html` 即可（Chrome / Edge / Safari / 微信内置浏览器均可）。

需要在手机上预览时，可在本机起一个静态服务，然后手机访问同一 Wi-Fi 下的电脑 IP：

```powershell
npx serve .
```

## 部署到 GitHub Pages

1. 登录 github.com，新建一个 **Public** 仓库（例如 `magic-cube-panel`）
2. 仓库页 → **Add file → Upload files** → 把 `index.html`、`robots.txt`、`README.md` 拖进去 → **Commit changes**
3. 仓库 **Settings → Pages** → Branch 选 `main`、目录选 `/ (root)` → **Save**
4. 约 1 分钟后访问 `https://<你的用户名>.github.io/magic-cube-panel/`

更新页面时重复第 2 步。Pages 有几分钟 CDN 缓存，如果客户看到旧版本，让他在链接后加 `?v=2` 或强制刷新。

页面里的 `robots.txt` 已禁止搜索引擎收录，链接不会被搜索到；但链接本身是公开的，拿到链接的人都能打开。

## 修改参数

所有可调项都在 `index.html` 的 `<script>` 顶部：

```js
var MODES = [
  { key: 'custom', name: '自定义模式' },
  { key: 'mellow', name: '醇养模式', temp: 20, hum: 65 },   // 这里的温湿度是预设值
  { key: 'wake',   name: '醒茄模式', temp: 20, hum: 75 }
];
var LIMIT = { temp: [16, 22], hum: [60, 80] };              // 自定义模式可调范围
```

- 改预设值：改 `MODES` 里对应模式的 `temp` / `hum`
- 改可调范围：改 `LIMIT`
- 改自定义模式初始值：`state.customTemp` / `state.customHum`（默认 20 / 70）
- 改灯光初始档位：`state.light`（1 低、2 中、3 高）
- 报障灯：`state.fault` 默认 `false`；界面未暴露开关，如演示需要可改为 `true`
  （当前样式在 `.lamp--fault`）

## 实现说明

- 排版单位：`--s` 为横屏每个布局单位的像素（`--k` 为设计稿单位），横竖屏各自一套比例
- 触摸区：箭头按钮最小 40×34px（竖屏 44×42），图标按钮带 padding，桌面端可用键盘操作
- 动效：Web Animations API，连点时先取消上一次动画；系统开启「减少动态效果」时自动关闭
- 点击音：WebAudio 实时合成，无音频文件；首次点击后启用（浏览器自动播放限制）
- 竖屏下温湿度分两行，每组箭头紧邻对应数值；横屏保持设计稿的「左箭头对调温度、右箭头对调湿度」
